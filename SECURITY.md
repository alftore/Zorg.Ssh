# Security policy

## Supported versions

Zorg.Ssh is in early development. Nothing has been released yet. After the first preview, only the latest published version gets security fixes.

## Reporting a vulnerability

Report it privately through the repository's **Security** tab, using **Report a vulnerability**. Don't open a public issue.

Please include the affected version, a way to reproduce it, and the impact you expect. A packet capture or a small hostile peer helps most.
